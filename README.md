An entry for make.fun's **"One Letter for Your Day"** bounty ($5 in USDC).

## The entry

The entry is the single letter above — nothing else.

## The word behind the letter

Zonked. Out cold by the end of the day, in the best way: the letter for sleep itself.

## How it works

`main.ts` (Node 22+, stdlib only, no network, deterministic) writes exactly one letter — `Z`, 1 byte, no trailing newline — to `$OUTPUT_DIR/entry.txt` (default `/output`):

```sh
OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
